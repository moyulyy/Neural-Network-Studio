NeuroStudio 参数说明

本页解释界面中各项参数的含义、算法与使用建议。点击参数旁的「!」可直接定位到对应条目。

数据与任务 网络结构 训练参数 评价指标

数据与任务

任务类型（回归 / 分类）

任务类型决定输出层维度、损失函数和评价指标。

  • 回归：标签是连续数值，模型输出一个实数，使用 MSE / MAE / Huber 等损失，常用 R²、RMSE、MAE 评价。
  • 分类：标签是离散类别，输出维度等于类别数，使用交叉熵损失，常用准确率、精确率、召回率、F1、AUC 评价。

应用会根据标签列自动推断任务，也可以手动切换。分类模型输出各类别的概率，预测类别为概率最大的那一类。

缺失值处理

  • 均值填充：用该数值特征在训练集上的均值填充缺失值。
  • 中位数填充：用中位数填充，对异常值更稳健。
  • 众数填充：用出现次数最多的值填充，数值与类别特征都可使用。
  • 删除缺失行：删除特征或标签缺失的样本。会减少样本量。

填充统计量只在训练集上计算，并保存进模型包；测试集使用完全相同的统计量，避免数据泄漏。

类别特征编码

  • One-Hot：一个有 N 个类别的列展开为 N 个 0/1 神经元。适合无序类别，但类别很多时会显著增加输入维度。
  • 序数编码：把类别映射为整数 0..N−1，只占 1 个输入维度。适合天然有序的类别；对无序类别可能引入虚假的大小关系。

编码字典在训练时固定，测试集中未出现过的类别在 One-Hot 下编码为全 0，在序数编码下为 −1。

特征标准化

对数值特征做 z-score 标准化：

z = (x − μ) / σ

其中 μ、σ 为训练集上的均值和标准差（σ=0 时取 1）。标准化能让不同量纲的特征处于相近尺度，通常可以加快收敛、提高训练稳定性。类别编码列不参与标准化。

网络结构

输入层、隐藏层与输出层

  • 输入维度：由所选特征与编码方式决定。数值特征 1 维；One-Hot 类别特征占类别数维；序数编码占 1 维。
  • 隐藏层：每层执行 Linear → (BatchNorm) → 激活 → (Dropout)。层数与每层宽度决定表达能力。
  • 输出维度：分类等于类别数，回归为 1。这样输出张量才能与交叉熵标签或回归目标严格对齐。

可训练参数量的近似计算：每个 Linear 层有 in×out + out 个参数；启用 BatchNorm 时每层再增加 2×out 个参数。

激活函数

  • ReLU：f(x)=max(0,x)。计算快、缓解梯度消失，是最常用的默认选择；负半轴梯度为 0。
  • LeakyReLU：f(x)=max(αx,x)，默认 α=0.01，负半轴保留很小的梯度。
  • GELU：f(x)=x·Φ(x)，Φ 为标准正态 CDF，曲线平滑，常用于 Transformer 类模型。
  • SiLU / Swish：f(x)=x·sigmoid(x)，平滑且非单调。
  • Tanh：输出 (−1,1)，零中心，但深层网络容易饱和。
  • Sigmoid：输出 (0,1)，常用于二分类输出层；隐藏层中易饱和。
  • ELU：负半轴为 α(e^x−1)，均值更接近 0。
  • SELU：自归一化激活，配合特定初始化与正则化使用。

权重初始化

  • Kaiming 均匀 / 正态：按 fan_in 缩放，适合 ReLU 类激活。均匀版本在 [-bound, bound] 采样，正态版本标准差约 sqrt(2/fan_in)。
  • Xavier 均匀 / 正态：兼顾 fan_in 与 fan_out，适合 Tanh / Sigmoid 等对称激活。
  • 正态 (σ=0.02)：小方差高斯初始化，常用于较浅网络。

偏置项默认初始化为 0 附近的小均匀随机数。初始化只影响训练起点，不会改变网络结构。

Dropout

训练时以概率 p 随机将隐藏神经元输出置 0，并把保留的神经元按 1/(1−p) 放大；推理时关闭 Dropout。

作用相当于对大量子网络做隐式集成，能抑制过拟合。数据量小、模型容量大时可尝试 0.1–0.5；数据量很大时通常不需要。

BatchNorm（批归一化）

对每个隐藏层的 mini-batch 激活做标准化，再学习缩放 γ 与偏移 β：

y = γ · (x − μ_batch) / sqrt(σ_batch² + ε) + β

它能让各层输入分布更稳定，允许更大的学习率。推理时使用训练阶段累计的 running mean / var。批大小过小时统计量不稳定；应用会自动跳过大小为 1 的批次。

训练参数

训练轮数（Epochs）

完整遍历训练集一次称为一个 epoch。轮数太少会欠拟合，太多可能过拟合。配合早停与验证集使用更可靠。

批大小（Batch Size）

每次参数更新使用的样本数。小批量噪声更大、泛化有时更好，但训练更慢；大批量梯度更稳定、吞吐更高，但可能占用更多显存，且泛化性能可能下降。

学习率（Learning Rate）

参数更新的步长。过大会震荡甚至发散，过小则收敛缓慢。常用起点：Adam 1e-3，SGD 1e-2 左右；配合学习率策略可进一步调整。

优化器

  • SGD（含 momentum）：v ← μv + g，θ ← θ − lr·v。简单、泛化好，但需要调学习率。
  • Adam：同时估计梯度一阶矩 m 与二阶矩 v，并做偏差修正： θ ← θ − lr·m̂ / (sqrt(v̂) + ε)。对超参数不敏感，适合快速起步。
  • AdamW：Adam + 解耦权重衰减，正则化更符合原始定义，常用于深度网络。
  • RMSprop：按梯度平方的指数移动平均缩放学习率，适合非平稳目标。

损失函数

  • MSE：(1/n)Σ(y−ŷ)²，对大误差敏感，回归默认选择。
  • MAE：(1/n)Σ|y−ŷ|，对异常值更稳健。
  • Huber：误差小于 δ 时用平方，大于 δ 时用线性，兼顾平滑与鲁棒性。
  • Smooth L1：Huber 的平滑版本，常用于回归。
  • 交叉熵（CrossEntropy）：分类默认损失。L = −Σ y_c log(p_c)，输出层需给出 logits；应用内部自动做 softmax。

类别权重与标签平滑只对分类交叉熵生效。

类别权重（Class Weight）

当类别样本数不平衡时，可给少数类更高权重。选择「平衡」时：

w_c = N / (K · N_c)

其中 N 是训练样本总数，K 是出现的类别数，N_c 是类别 c 的样本数。权重传入交叉熵，使各类对总损失的贡献更均衡。

标签平滑（Label Smoothing）

把硬标签 onehot(c) 替换为：

target = (1−ε)·onehot(c) + ε/K

ε 通常取 0.05–0.1。它可以抑制模型过度自信、改善校准与泛化，但会略微降低训练集置信度。

验证集比例

从训练数据中留出用于监控的比例（0–0.5）。分类任务按类别分层抽样，保证每类在验证集中都有样本。验证损失用于早停和恢复最佳权重；0 表示不划分验证集。

学习率策略

  • 固定：整个训练使用同一学习率。
  • 余弦退火：lr_t = lr_min + 0.5(lr_max−lr_min)(1+cos(πt/T))，前期大、后期小，收敛平滑。
  • 阶梯衰减：每隔固定轮数乘以 0.5，简单直接。

权重衰减（L2 正则）

在损失中加入 (λ/2)||w||²，抑制权重过大。AdamW 使用解耦衰减。常用范围 0–1e-2；过大会导致欠拟合。

梯度裁剪

当梯度的全局范数超过阈值时按比例缩小：g ← g · clip/||g||。能抑制梯度爆炸，RNN 与深层网络常用；表格 MLP 通常可以设为 0 关闭。

早停（Early Stopping）

若验证损失连续 N 个 epoch 没有改善，则提前结束训练，并恢复验证损失最低的那一轮权重。N=0 表示关闭。它能节省时间并降低过拟合。

随机种子

控制权重初始化、数据打乱与 Dropout 等随机过程。相同种子、相同环境与设备下结果应可复现；CUDA 的某些算子仍可能存在非确定性。

计算设备

自动优先使用 CUDA，否则 CPU；也可以强制选择。CPU 适合小模型与调试，GPU 适合较大批量与深层网络。

评价指标

R²（决定系数）

R² = 1 − Σ(y−ŷ)² / Σ(y−ȳ)²。越接近 1 越好，0 表示与直接预测均值相当，负值表示比均值预测更差。

RMSE（均方根误差）

sqrt(mean((y−ŷ)²))，与目标同量纲，对大误差敏感。

MAE（平均绝对误差）

mean(|y−ŷ|)，直观且对异常值不如 RMSE 敏感。

MAPE（平均绝对百分比误差）

mean(|y−ŷ| / |y|) × 100%。便于跨量纲比较，但真实值接近 0 时会不稳定，应用会忽略这些样本。

准确率（Accuracy）

预测正确的样本比例。类别不平衡时可能产生误导，建议同时查看精确率、召回率、F1 与 MCC。

精确率（Precision）

对每个类别：TP / (TP + FP)，表示预测为该类的样本中真正属于该类的比例。应用展示 macro 平均，即对各类取平均。

召回率（Recall）

对每个类别：TP / (TP + FN)，表示该类真实样本被找出的比例。macro 召回率也称为平衡准确率。

F1 分数

2·Precision·Recall / (Precision + Recall)，精确率与召回率的调和平均。应用展示 macro F1。

特异度（Specificity）

对每个类别：TN / (TN + FP)，表示其他类别被正确排除的比例。应用展示 macro 特异度。

ROC-AUC

ROC 曲线下面积，衡量模型把正类排在负类前面的能力。二分类直接计算；多分类使用 one-vs-rest 后取宏平均。0.5 相当于随机，1.0 为完美排序。它不依赖具体分类阈值。

MCC（Matthews 相关系数）

综合混淆矩阵四个象限的指标，范围 [−1,1]。多分类使用混淆矩阵推广形式。类别不平衡时比准确率更可靠；0 表示随机，1 表示完美。

Cohen's κ

衡量预测与真实标签的一致性，并扣除随机一致的概率：

κ = (p_o − p_e) / (1 − p_e)

其中 p_o 为观察一致率，p_e 为随机期望一致率。0 左右表示与随机相当，1 为完全一致。

Log Loss（对数损失）

分类概率的交叉熵：−mean(log p_true)。它同时惩罚错误类别和过度自信，越小越好。需要模型输出概率。

提示：分类指标中的 macro 平均会先对每个出现的类别计算指标，再取算术平均。混淆矩阵的行是真实类别、列是预测类别。
